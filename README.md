# CaijuCraft pack

The mod list (`pack.json`) and releases of the Caiju Launcher for the CaijuCraft server.
The launcher reads this file every time it opens, so mod changes reach every player
automatically.

**Download the launcher:** [CaijuLauncher.exe](https://github.com/lucy-dot-exe/caijucraft-pack/releases/latest/download/CaijuLauncher.exe)
